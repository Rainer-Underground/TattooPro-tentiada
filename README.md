# Tattoo Ink Mixer Pro

Uma aplicação web progressiva (PWA) para tatuadores profissionais, focada em mistura de tintas, estudo de colorimetria e gestão de estúdio.

## Funcionalidades Principais

*   **Misturador de Tintas (Ink Mixer):** Crie cores personalizadas simulando misturas reais gota a gota com as cores primárias + preto e branco.
*   **Estudo de Cores:** Círculo cromático interativo para visualizar harmonias (Complementar, Análoga, Triádica) com exemplos de aplicação na pele.
*   **Calculadora de Orçamentos:** Precifique suas tatuagens com base em hora de trabalho ou tamanho (cm²), com configurações personalizáveis de taxas e valores mínimos.
*   **Controle de Estoque:** Gerencie tintas, agulhas e materiais. Receba alertas de estoque baixo e refaça pedidos diretamente na **Electric Ink** ou busque ofertas no **Google Shopping**.
*   **Agenda Digital:** Organize suas sessões com cálculo automático de valores e status (Pendente, Confirmada, Concluída).
*   **Gestão de Clientes:** Salve fichas completas com contatos, histórico e notas sobre alergias/preferências.

## Como Usar

1.  Clone este repositório.
2.  Abra a pasta do projeto.
3.  Execute `start_app.bat` (no Windows) para iniciar o servidor local automaticamente.
    *   Ou execute `node server.js` no terminal.
4.  Acesse `http://localhost:8080` no seu navegador.
